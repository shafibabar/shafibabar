Native AI Products

AI and ML built into the product, from an LLM reasoning layer to NLP prioritization and predictive models, plus agent skill systems I build and test myself.

Caizin · Client: Smarsh · 2026

Observability Copilot

An AI reasoning layer over the team's Datadog stack. An engineer asks a plain-language question; the Copilot pulls the relevant telemetry, rebuilds the incident timeline, and reports Facts, Hypotheses, Recommendations, and Unknowns, each with a confidence level and a link to its evidence. The dashboard stays the source of truth.

  • Adopted: part of the incident management process; Support uses it without being required to.
  • Maps plain-language terms to ~320 production metric queries and queries only the 8 most relevant, keeping cost and latency down.
  • Two-stage guard (a deterministic filter, then an LLM classifier that fails closed) blocks prompt injection and off-topic use before expensive reasoning runs.
  • Directed end to end with an AI coding agent under TDD and approval gates: 299 tests, 98% coverage, 4 iterations in 5 weeks.
  • Python
  • FastAPI
  • Claude API
  • Claude Code
  • Pydantic
  • SQLite
  • Datadog (read-only)

SaaS Platforms

Multi-tenant, high-reliability platforms in regulated domains: surveillance, healthcare interoperability, and financial data.

Caizin · Client: Smarsh · 2024–present

Enterprise Conduct streaming platform

Platform roadmap owner for Smarsh's communications-surveillance system for Tier-1 banks, across ingestion, processing, indexing, reporting, and actionability.

  • Re-architected the core pipeline from Apache Storm batch to streaming microservices: ~15M messages/day, 300/sec at peak, on a true multi-tenant platform.
  • Cut ~30% of platform COGS by spreading processing load across the day instead of a fixed compute window.
  • Deterministic terminal-state model: every message reaches a guaranteed, auditable final state.

Caizin · Client: Smarsh

Enterprise Conduct pipeline explainer

An interactive isometric simulation that lays the surveillance pipeline out as a factory floor and animates one message through it end to end. Queue depth, autoscaling, retries, and end-to-end latency respond live to workload sliders.

  • Used with customers to size infrastructure and set performance expectations from their projected daily workloads.
  • Models 16 real platform services: 8 on the main line, 2 downstream consumers, 6 supporting systems.
  • Documents a fidelity boundary (computed, assumed, or simplified) so viewers know how far to trust it.
  • Tested like product code: an end-to-end smoke test through every state and an idle check proving nothing animates without cause.
